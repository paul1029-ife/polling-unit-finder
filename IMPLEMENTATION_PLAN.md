# Implementation plan

1. Scaffold a separate Next.js App Router / TypeScript / Tailwind project. Existing projects are untouched. create-next-app's filesystem access preflight failed under the sandbox; use the same standard minimal scaffold manually.
2. Use the MIT-licensed nigeria-inec-geo CSV snapshot, pinned to 3cf617721aea519eef960681d3d86a4fad4325da, a community transcription of INEC's CVR directory. Validate unique codes, hierarchy and counts at import. Official comparator: https://inecnigeria.org/polling-units/ (176,846 units, 774 LGAs, 8,809 wards). This is a snapshot, not an official live API.
3. Reject mykeels/inec-polling-units coordinates: its lookup-geocode.script.js uses the first Google Places text-search result, sample coordinates land in Canada, and repeated coordinates suggest area centroids. They are unsuitable for precise nearest-unit claims.
4. Keep canonical polling-unit records server-side behind a small repository and paginated API. Provide replaceable, validated verified-coordinate overlay keyed by official full code. Never infer coordinates from names or hierarchy.
5. Use Leaflet/react-leaflet with attributed OpenStreetMap tiles, loaded only on the client. Render markers only for verified coordinates. Unknown locations remain searchable in the list; map explains missing coverage. Browser geolocation is requested only by explicit button click, remains in memory, and is sent only to the same-origin search endpoint. Haversine straight-line distance ordering applies exclusively to verified records. With this snapshot, nearby search returns an honest coverage fallback rather than invented results.
6. Build a mobile-first civic search interface with cascading State/LGA/Ward controls, name/code search, list/map toggle, pagination, detail dialog, and Google Maps directions. Missing-coordinate directions use a clearly labeled place search rather than a precision pin.
7. Validate data integrity, search/filter/pagination and distance functions; run lint, TypeScript and production build, then exercise HTTP API and browser UI.
